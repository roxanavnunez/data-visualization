# Python Crash Course - Chapter 15-17: Data Visualization

This repository contains my work and exercises from Chapters 15, 16, and 17 of the book "Python Crash Course". The projects focus on data visualization with Matplotlib and Plotly Express, working with data files (CSV, JSON), and consuming web APIs (GitHub API and Hacker News API).

## 📖 About This Project

This project serves as a practical application of the concepts learned in the second part of "Python Crash Course." It explores generating visualizations with Matplotlib, processing data from files, and creating interactive charts from web API data using Plotly.

## ✨ Features

**Chapter 15: Data Visualization with Matplotlib**
* **Random Walks:** Visualizing random paths.
* **Dice Simulation:** Creating histograms from dice roll data.
* **Scatter Plots:** Customizing simple scatter and line plots.

**Chapter 16: Downloading Data**
* **CSV Data Processing:** Parsing and visualizing CSV data, such as global temperature and rainfall information.
* **JSON Data Handling:** Working with JSON-formatted data, like mapping global earthquake epicenters.

**Chapter 17: Working with APIs**
* **API Calls:** Using the requests library to interact with web APIs (e.g., GitHub, Hacker News).
* **Interactive Plotting:** Creating dynamic and interactive charts from API data with Plotly.

## 🚀 Getting Started

### Prerequisites

* Python 3.x
* Matplotlib
* Plotly
* Pandas
* Requests
* Pytest

### Setup and Installation

To clone and run this project locally, follow these steps:

1.  **Clone the repository:**
    ```sh
    git clone [https://github.com/roxanavnunez/data-visualization.git]
    ```
2.  **Navigate to the project directory:**
    ```sh
    cd data_visualization
    ```
3.   **(Recommended) Create and activate a virtual environment:**
   ```sh
    # For macOS/Linux
    python3 -m venv venv
    source venv/bin/activate

    # For Windows
    python -m venv venv
    venv\Scripts\activate
   ```

4. **Install the required packages:**
    ```sh
    pip install matplotlib plotly pandas requests pytest
    ```

## Usage

Each Python file (`.py`) in this repository corresponds to a specific example or exercise. The scripts are organized by chapter, reflecting the concepts being practiced. 

You can run any of them to see the output plot:

```sh
python name_of_the_script.py
```
